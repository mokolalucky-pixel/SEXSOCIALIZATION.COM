## Key Questions for Each Provider

### Legal & Compliance
- [ ] Do you comply with POPIA Section 26 (Special Personal Information)?
- [ ] What is your FICA/AML registration status in South Africa?
- [ ] Provide a current Data Processing Agreement (DPA) template
- [ ] Are you compliant with GDPR for EU/cross-border data flows?
- [ ] What data breach notification process do you follow?

### Data Handling & Retention
- [ ] What is your raw biometric data (photo, liveness) retention policy?
- [ ] How quickly after verification do you delete raw artifacts?
- [ ] What encryption standards do you use (at rest and in transit)?
- [ ] Where is data stored geographically?
- [ ] Can you provide deletion confirmation for audit/compliance?

### Verification Quality
- [ ] What is your liveness detection accuracy rate (%)?
- [ ] False positive rate? False negative rate?
- [ ] How do you handle edge cases (masks, poor lighting, etc.)?
- [ ] Manual review process and turnaround time?
- [ ] Can you provide test credentials for sandbox/demo?

### Integration & Technical
- [ ] What SDKs/APIs do you offer? (Python, Node.js, React, etc.)
- [ ] API documentation quality and code examples?
- [ ] Typical integration timeline?
- [ ] Sandbox environment availability?
- [ ] Webhook/callback support for asynchronous verification?

### Pricing & Commercial
- [ ] Cost per successful verification?
- [ ] Cost per failed attempt?
- [ ] Volume discounts (1000+, 5000+, 10000+ monthly)?
- [ ] Setup/onboarding fees?
- [ ] Minimum contract term and termination clauses?
- [ ] Currency (ZAR, USD, EUR)?

### Support & Operations
- [ ] Support availability (hours, channels: email, chat, phone)?
- [ ] SLA for critical issues?
- [ ] Uptime guarantee?
- [ ] Change log and API versioning policy?
- [ ] Incident reporting and communication process?
