# Data Processing & Operator Summary

**Last Updated:** 2026-09-02  
**Status:** Draft pending legal + vendor-contract review

## 1. Roles under POPIA
- **Responsible Party:** sexsocialization.com
- **Operators (examples):** Ozow, Paystack, Neon, Vercel (role depends on exact processing purpose and contract)

## 2. Payment Processing Scope
Payment operators should process only the minimum required billing data, for example:
- Amount
- Transaction reference
- Email/contact identifier

No unnecessary special personal information should be sent to payment operators.

## 3. Required Agreements
Data Processing Agreements (or equivalent operator clauses) should be executed with:
- Ozow
- Paystack
- Neon
- Vercel

> **Legal review required:** finalize controller/operator allocations, sub-operator lists, and cross-border clauses.

## 4. Security Baseline
- Encryption in transit
- Encryption at rest
- Least-privilege access controls
- Audit logging for sensitive events
- Incident response process

## 5. Cross-Border Processing
Where operator infrastructure is outside South Africa, cross-border transfers must comply with POPIA Section 72.

## 6. Records and Accountability
Maintain records of:
- Data mapping
- Operator contracts
- Security controls
- Breach management actions
- Consent records (where applicable)
